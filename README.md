# ML Projects

A curated collection of end-to-end machine learning projects showcasing data preprocessing, model training, evaluation, and deployment across diverse real-world domains.

## 🚀 Projects

| Project | Description | Tech Stack |
| --- | --- | --- |
| [**E-Commerce FAQ Bot**](E_commerce_FAQ_Bot/README.md) | Intelligent chatbot that answers e-commerce support queries using NLP and Jaccard similarity with both CLI and Streamlit interfaces. | `Python`, `NLTK`, `Streamlit`, `JSON` |
| [**Fake News Detection**](Fake_News_Detection/README.md) | TF-IDF vectorization with Logistic Regression to classify news articles as fake or real, featuring an interactive Streamlit frontend. | `Python`, `scikit-learn`, `NLTK`, `Streamlit` |
| [**House Price Predictions API**](House%20price%20predictions%20Api/README.md) | RESTful API for predicting house prices using regression models with structured data preprocessing and inference endpoints. | `Python`, `Flask/FastAPI`, `scikit-learn`, `pandas` |
| [**Instagram Fake Account Detection**](Instagram-fake-account-detection/README.md) | Logistic Regression-based classifier that identifies fake Instagram accounts using profile-level features like followers, following, and engagement metrics. | `Python`, `scikit-learn`, `pandas`, `NumPy` |
| [**Phishing Website Detection**](Phising_website_detection/README.md) | Random Forest classifier that detects phishing websites by analyzing 30+ encoded URL, domain, and webpage-based features. | `Python`, `scikit-learn`, `pandas`, `NumPy` |
| [**Spam Classifier (Naive Bayes)**](Spam_classifier_Naive_Bayes/README.md) | Email/SMS spam detection using Naive Bayes algorithm with text preprocessing and TF-IDF feature extraction. | `Python`, `scikit-learn`, `NLTK`, `pandas` |
| [**SQL Injection Detector**](sql-injection-detector/README.md) | Machine learning-based approach to detect and classify SQL injection attempts from query patterns. | `Python`, `scikit-learn`, `NLTK`, `pandas` |
