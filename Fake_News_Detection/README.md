# Fake News Detection

Binary classification of news articles as **Fake** or **Real**, using TF-IDF features
and a logistic regression classifier, with a Streamlit frontend.

The pipeline uses a `GroupShuffleSplit` keyed on article body so duplicate articles
stay on one side of the train/test boundary. This matters: the corpus contains 5,628
duplicate text rows (5,138 repeated article bodies), so a plain random split would
leak near-identical text into the test set.

## Frontend

```bash
uv run streamlit run app.py
```

The app loads the saved `.pkl` artifacts and provides:

- A demo-article selector covering easy and tricky real/fake examples.
- Title and article-body inputs.
- A verdict card with a confidence score and a P(Real)/P(Fake) breakdown.
- An expected-label comparison when a demo article is selected.
- A disclaimer that the tool is a demonstration, not a fact checker.

The sidebar reports the group-split accuracy (**0.9861**). If the model artifacts are
missing, the app shows an error instead of starting.

## Dataset

The [Fake and Real News Dataset](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset)
(originally the ISOT Fake News Dataset), two CSV files of news articles:

| File | Rows | Label |
| --- | --- | --- |
| `data/raw/True.csv` | 21,417 | `1` (Real) |
| `data/raw/Fake.csv` | 23,481 | `0` (Fake) |

Columns: `title`, `text`, `subject`, `date`. The real articles are Reuters wire
stories; the fake articles come from various fake-news outlets.

## Method

1. Load both files, stamp the labels, concatenate and shuffle (`random_state=42`).
2. Drop the 631 rows whose `text` is blank after stripping (44,267 remain).
3. Build `combined_text = title + " " + text`.
4. Vectorize with `TfidfVectorizer(max_features=50000, ngram_range=(1, 2),
   stop_words="english", min_df=2, max_df=0.95)`.
5. Fit `LogisticRegression(max_iter=1000, random_state=42, C=1.0)`.
6. Evaluate on the grouped split, save artifacts, and inspect misclassifications.

## Results

44,267 usable rows. `GroupShuffleSplit(test_size=0.2)` produces 35,432 training rows
and 8,835 test rows, with zero overlapping article bodies. The vectorizer hits its
50,000-feature cap.

**Accuracy (group split): 0.9861**

| Class | Precision | Recall | F1 | Support |
| --- | --- | --- | --- | --- |
| Fake (0) | 0.99 | 0.98 | 0.99 | 4,511 |
| Real (1) | 0.98 | 0.99 | 0.99 | 4,324 |

Confusion matrix (`0 = Fake`, `1 = Real`):

```
[[4435   76]
 [  47 4277]]
```

123 test articles were misclassified: 76 fake articles were called real and 47 real
articles were called fake.

### Duplicate analysis

| Metric | Value |
| --- | --- |
| Duplicate text rows | 5,628 |
| Texts appearing more than once | 5,138 |
| Conflicting-label text groups | 0 |

No article body carries both labels, so grouping on `text` removes duplicate leakage
without creating label conflicts.

### Where the model still fails

The highest-confidence miss is a real article formatted as `Text: Mitt Romney speech
slamming Donald Trump`, classified fake with 0.998 confidence. The next several
high-confidence misses are fake articles with sensational all-caps headlines (North
Korea missile tests, Russia/Obama stories) that the model reads as real. Some
duplicate titles appear more than once in the error list.

The pattern is consistent with a bag-of-words model keying on stylistic register
rather than veracity. Source metadata, author, and image/URL features would be the
natural next inputs.

## Setup

Requires Python >= 3.12. With [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Or install the dependencies directly with pip:

```bash
pip install joblib pandas scikit-learn streamlit
```

## Data

`data/raw/` is not tracked in git (~111 MB). Download `True.csv` and `Fake.csv`
into `data/raw/` before running.

## Usage

Train the model and write both artifacts to the project root:

```bash
python main.py
```

- `fake_news_model.pkl` — the fitted `LogisticRegression`
- `tfidf_vectorizer.pkl` — the fitted `TfidfVectorizer`, needed to transform new
  input at prediction time

Then launch the frontend:

```bash
uv run streamlit run app.py
```

Both artifacts are gitignored; regenerate them by rerunning `main.py`.
